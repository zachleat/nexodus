The best path forward is to empower developers to write HTML and CSS in the editor of their choosing. Any abstraction that hampers that (whether it’s a web site builder or ✨Tailwind✨) has (in my experience) inhibited productivity and increased long-term maintenance costs.

> The most disappointing thing about Figma sites is that they fell into the same trap as almost every other website builder.
> 
> They assumed (arrogantly) that HTML and CSS are over engineered and that they can make it much simpler.
> 
> They are not alone. So many tools before them has done the same.

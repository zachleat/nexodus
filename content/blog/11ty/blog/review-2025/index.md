\<p>It was \<em>another huge\</em> year for 11ty. We shipped \<em>177 releases\</em> (73% more than 2024) across the full \<code>11ty/\*\</code> suite. We closed 804 issues (15% more than 2024). We reduced core’s \<a href="https://www.11ty.dev/blog/dependency-watch/">dependency count by 28% and weight by 22%\</a>. More folks are building with Eleventy than ever: our year-over-year npm downloads (for only core) are up by 51%! \<strong>Eight years into this roller coaster of an open source project and it still feels like we’re just getting started!\</strong>\</p> \<p>\<em>You can \<a href="https://www.11ty.dev/blog/review-2024/">also read last year’s Eleventy, 2024 in Review\</a>.\</em>\</p> \<h2 id="highlights">Highlights\</h2> \<p>Here is a small, curated collection of 2025 highlights:\</p> \<ul> \<li>In April, we moved to our \<a href="https://neighborhood.11ty.dev/@11ty">own Mastodon server\</a>. Also the \<a href="https://eleventy-libdoc.netlify.app/">amazing Eleventy LibDoc community starter project\</a> first shipped!\</li> \<li>In May, we shipped a sizeable \<a href="https://github.com/11ty/eleventy/releases/tag/v3.1.0">v3.1.0 release\</a> focused on reducing dependencies and improving build performance! We also shipped an \<a href="https://neighborhood.11ty.dev/@11ty/114519676689929120">interactive playground component to the docs\</a> (Eleventy in the browser!).\</li> \<li>In June, we were featured in a \<a href="https://www.youtube.com/watch?v=4\_bYUVGgQQo">video on the Veronica Explains YouTube channel\</a>!\</li> \<li>In July, we started \<a href="https://www.11ty.dev/docs/versions/">shipping 4.x alpha pre-releases\</a>!\</li> \<li>In August, I found an \<a href="https://www.zachleat.com/web/history-of-eleventy-name/">old note from my late grandmother about the origins of the Eleventy name\</a>.\</li> \<li>In September, we found our \<a href="https://neighborhood.11ty.dev/@11ty/115226254940993358">logo added to the Font Awesome v7 icon set\</a>!\</li> \<li>In October, we changed the docs \<a href="https://www.zachleat.com/web/permanent-eleventy-facepile/">supporter facepile to include emeritus individual supporters\</a> and shamefully \<a href="https://www.zachleat.com/web/copy-paste/">added long-awaited copy-paste buttons\</a>.\</li> \<li>In November, we \<a href="https://www.11ty.dev/blog/github-issues/">rehauled how we use GitHub Issues\</a> and made a bunch of long-overdue progress on our Issue tracker. \<a href="https://neighborhood.11ty.dev/@guaca@toot.cafe/115553703597032584">Estela Franco also showed us their Eleventy source code backpack\</a>\</li> \<li>In December, we \<a href="https://www.11ty.dev/blog/npm-security/">improved our security footprint by eliminating Access Tokens from our npm package publishing process\</a>. \<ul> \<li>We simplified our historical docs by centralizing to \<a href="https://neighborhood.11ty.dev/@11ty/115663215128943589">v0, v1, v2, and v3 subdomains\</a>.\</li> \<li>We improved the docs for \<a href="https://www.11ty.dev/docs/cjs-esm/">different flavors of JavaScript\</a> (CommonJS, ESM, and TypeScript) to use in Eleventy (including guidance on Node’s new type stripping features).\</li> \</ul> \</li> \<li>With a special sustained community nod to the \<a href="https://11tybundle.dev/blog/">×17 11ty Bundle Newsletters\</a> and \<a

You shouldn’t have to maintain security hypervigilance to run a web site.\</li> \<li>Developers face \<em>too much\</em> infrastructure lock-in when shipping dynamic features (\<em>especially\</em> in the JavaScript tooling ecosystem). Perhaps you’ve been eyeing the \<a href="https://www.zachleat.com/web/serverless-cost/">per-compute pricing on your serverless bill\</a> as bot traffic increases over time.\</li> \<li>Adding collaborative editing and content management features to your static web site requires more configuration work than it should to get up and running.\</li> \</ol> \<p>\<strong>Build Awesome Pro\</strong> is a new web site builder that attempts to solve each of these problems. Fast by default, durable over time, with way less dependency drama. Build Awesome Pro will feature:\</p> \<ol> \<li>Static output. Versioned in git. Build and deploy wherever you’d like.\</li> \<li>Bring your own project or choose from our curated list of starter templates. Have an Eleventy project? We’ll maintain full compatibility with existing Eleventy projects and the Eleventy ecosystem.\</li> \<li>No lock-in. Edit and collaborate on our infrastructure. Host anywhere (optionally with us). Eject at any time with your site as-is.\</li> \</ol> \<p>Build Awesome Pro offers the option to add \<strong>collaborative editing to your project as an infrastructure-level Progressive

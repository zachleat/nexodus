Did you know? Eleventy v3 shipped with JavaScript front matter built-in (no plugin or extra config needed!)

Use ---js to enable it. Easier than a separate JavaScript data file!

Learn more: [https://www.11ty.dev/docs/data-frontmatter/#java-script-front-matter](https://www.11ty.dev/docs/data-frontmatter/#java-script-front-matter)

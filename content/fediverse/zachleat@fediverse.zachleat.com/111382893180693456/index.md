Confession: in my Web Components journey I’ve used Shadow DOM on a few components and it made sense to do so and it worked well (no regrets).

Remember that these different styles of component are tools in the toolbox.

Shadow DOM isn’t a silver bullet (or even a good default choice) but when you understand the tradeoffs you’re making and weigh those against the purpose and use case of the component, it sometimes makes sense to use it!

(And if you’re new to Web Components, don’t start here)

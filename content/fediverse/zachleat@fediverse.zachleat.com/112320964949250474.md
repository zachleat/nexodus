Next.js static export not supporting \`next/image\` is \*wild\*.

“Since Next.js supports this static export, it can be deployed and hosted on any web server that can serve HTML/CSS/JS static assets.”

But not images!!

[https://nextjs.org/docs/pages/building\-your-application/deploying/static-exports#unsupported-features](https://nextjs.org/docs/pages/building-your-application/deploying/static-exports#unsupported-features)

This is a prime example of customers losing from an unhealthy relationship between framework and hosting provider.

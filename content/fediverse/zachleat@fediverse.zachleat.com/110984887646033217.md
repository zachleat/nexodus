This poll got a lot of responses (and helpful replies)!

I wasn’t all that interested in preferences 😅. I really wanted to learn about the folks that selected the first two options.

A few lessons:

1\. Supporting both modes is an accessibility priority—some folks need light, some dark.  
2\. Which mode folks need can be dependent on their surroundings (not just time of day).  
3\. Untested poor color contrast is a big problem!  
4\. UI toggles are used by folks as a workaround for color contrast issues.

Had a few minutes so I forked and updated one of my favorite (but never published) Filament Group classics:

\`flex-luthor\` is a flexbox helper to configure layouts using a few CSS custom properties.

Source: [https://github.com/zachleat/flex-luthor](https://github.com/zachleat/flex-luthor)  
Demo: [https://flex-luthor.zachleat.dev/](https://flex-luthor.zachleat.dev/)

This utility predated Flexbox \`gap\` but this new version uses it internally. Automatic horizontal/vertical border separators are probably its coolest feature!

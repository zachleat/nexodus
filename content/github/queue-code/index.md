# Queue Code

[https://queuecode.zachleat.dev/](https://queuecode.zachleat.dev/)

## Usage:

-   Press any key to reveal the next character of source code. Use delete to hide characters.
-   Use the `url` query parameter to point to a different source code file. e.g. [https://queuecode.zachleat.dev/?url=https://gist.githubusercontent.com/zachleat/a7393810acf7890e6bef6a34eaa7b78c/raw/smoothscroll.css](https://queuecode.zachleat.dev/?url=https://gist.githubusercontent.com/zachleat/a7393810acf7890e6bef6a34eaa7b78c/raw/smoothscroll.css)
-   Use the `format` query parameter to set the syntax. Not required if the url ends in html, js, or css.
-   Use the `autoplay` query parameter to show all of the code.
-   Use `autoplay=1` to reveal the code progressively (1 is the slowest speed, higher numbers will type faster)
-   Press \` to skip to the end and show all of the code.

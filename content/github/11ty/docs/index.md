-   [https://www.11ty.dev/](https://www.11ty.dev/)

The website and documentation for the [Eleventy static site generator](https://github.com/11ty/eleventy/).

## Running Locally

```
npm install
npm run get-new-data
npx @11ty/eleventy --serve
```

Browse to [http://localhost:8080/](http://localhost:8080/) (8080 is the default but it’ll bump to a new port if that one is taken, so use whatever port shows up when you run the `--serve` command).

-   Refresh Supporters: `npm run get-new-supporters`
